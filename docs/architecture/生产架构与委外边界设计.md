# 生产架构与委外边界设计

> 适用范围：产品分类、EBOM、生产 MBOM 分支、工序、产线归属、生产路线、在制品执行、委外/外协及其与订单、采购、APS 的边界。产品分类用于识别和展示，产线是独立主数据，EBOM 记录所属产线，MBOM 沿来源 EBOM 展示归属；MBOM 分支承载产品工序。产线归属只用于识别和展示，不参与生产执行。

## 当前业务模型

`ProductType` 是产品分类标签，例如“山地车圈”。它用于人员理解、检索和展示，不单独决定工序、路线、BOM 候选、客户归属或排产规则。`ProductTemplate` 只定义产品规格字段。

BOM 定义具体产品的物料组成，并承载配方版本和生命周期；MBOM 关联具体 `Product`，通过 `Product.typeId` 校验所属产品分类。EBOM 新建时单选一条有效产线并保存；MBOM 通过 `SourceEBOMID` 关联来源 EBOM，并只读展示该来源产线，不单独选择产线。BOM 内的 `BOMSection` 只是物料分组，不能推导生产工序。

MBOM 稳定分支身份为：

```text
productId + ownerType + ownerCustomerId + versionLevel
```

同一稳定分支在同一 BOM 类型下最多有一条 `RELEASED` 记录；修订时旧记录转为 `OBSOLETE`，再发布新记录。销售订单行单选一个有效 MBOM 稳定分支，不存在在同一分支下选择多个当前有效修订的业务流程。产品分类和有效 MBOM 分支可以作为订单页面的销售生产组合展示上下文，但实际生产约束和工序归属落在 MBOM 分支。分支中的 `productId` 用于识别和校验具体产品，不是订单上的另一个独立产品选择。

工序库维护正式、可复用的 `ProcessStep`。每个 MBOM 稳定分支预设允许工序及默认顺序，分支关联直接引用 `ProcessStep.id`。销售订单明细选择分类展示上下文和有效 MBOM 分支后默认继承该分支路线；仅在该订单对应 EMBOM 需要个性调整时，订单行才显式改用本单自定义路线。这个选择属于订单行，不是通用路线创建时的适用范围。

`ProductionLine` 是独立主数据；产线管理 TAB 维护产线名称、编码、说明和启停状态。EBOM 草稿必须单选一条有效产线，草稿可调整、发布后锁定；MBOM 不单独保存产线，详情从来源 EBOM 只读展示。该单一归属已实现，服务及 SQLite 回归已通过，PostgreSQL 专项回归因未配置测试数据库尚未执行。产线归属不决定订单行、生产计划、APS 资源或扫码执行。MBOM 分支工序及默认顺序由分支工序配置维护；订单路线负责订单实际使用工序及执行顺序。

订单行是商业需求身份。生产计划继承来源订单行的路线选择，并在排产时固定实际采用的路线快照。之后调整分支默认工序或订单自定义路线，不改写已绑定计划和条码；产线归属不参与计划身份。没有订单行来源的计划使用所选 MBOM 分支默认路线。

`SalesOrderLine` 持久化产品分类展示上下文、有效 MBOM 稳定分支及 `DEFAULT/CUSTOM` 路线方式。默认工序和顺序读取分支配置；只有选择本单自定义工序的订单行才在生产路线 TAB 配置路线。路线直接关联订单行，产品与 MBOM 分支由订单行带出，名称和编号由系统生成。MRP 与正式领料按订单行已选分支限定配方候选，并在正式下发时重新验证。

## 生产执行边界

产品一维码关联一个活跃执行批次和生产计划。计划固定路线修订，扫码服务根据条码状态与该修订确定当前路线步骤和工序；客户端提交条码、动作及作业地点，不自行指定路线或工序。路线步骤位置由 `routeStepId` 标识，路线步骤及执行事实直接引用工序库身份 `ProcessStep.id`。

实际生产地点由 `ProductionWorkLocation` 单独表达。MBOM 分支工序、路线步骤、生产地点、委外持有方及品质检验站是不同业务身份，不能互相代替。APS 资源与路线步骤的能力、时间和资源约束需要另行建模，不能从分类名称或 BOM 物料分组推导。

## 委外边界

委外是生产路线步骤的一种外部执行方式，归属生产管理域。委外单位和协议/价格属于生产委外资料；采购域继续负责结算、付款和供应商合作关系。采购供应商、设备合作方和委外单位只有在各自领域明确关联后才能互相引用，不能互相替代。

委外任务保存来源、产品快照和计划数量，不决定生产工序。扫码发出、回厂、检验及返工按产品一维码读取计划固定路线修订，并记录路线步骤、工序身份、委外持有方和检验结果。每个产品码代表一件；部分回厂通过不同产品码逐件记录。同一码支持厂内返工复检及再次委外，并按检验轮次和委外周期保留事实。

## 实施状态

截至 2026-11-26，独立工序库、MBOM 分支工序选配、销售订单行分类展示上下文和分支选择、订单行自定义路线、分支默认路线物化、计划绑定路线修订、条码固定路线执行、委外收发检验、复检轮次及重复委外周期已有实现和本地回归。路线候选受订单行所选有效分支及自定义模式约束，MBOM 分支关联、路线步骤和执行事实统一使用 `ProcessStep.id`，路线位置由 `routeStepId` 表示。

独立工序库、MBOM 分支工序配置、销售订单行路线方式、自定义路线、生产计划修订绑定、条码固定路线执行及委外收发检验已有实现和本地回归。实际执行地点由 `ProductionWorkLocation` 表达。MRP 与正式领料按订单行所选分支自动解析唯一有效 MBOM；重复有效发布作为完整性异常阻断，不提供手选。浏览器连接实际 API 的端到端验收、目标环境数据库核对和部署后业务验收仍待完成。
