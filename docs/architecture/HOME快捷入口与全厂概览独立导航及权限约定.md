# 首页快捷入口与全厂概览独立导航及权限约定

## 业务入口

- `/home` 是登录后的默认入口，左侧有独立菜单，中文名称为“首页”，英文名称为“Home”，域内只有“快捷入口”一个 TAB。
- 底部首页图标始终指向 `/home`，只在首页显示激活状态。
- 首页先增加“如何建立产品”操作引导，按顺序展示准备产品属性、配置产品模板、建立基础型号并关联模板、生成产品四步；建立 BOM 是保存产品后的按需后续步骤。每张卡片说明入口、操作、填写内容及完成结果；已有基础配置可直接复用。其他业务流程暂不扩展。
- 引导卡片引用现有产品模块 TAB 配置，包括已有的 `/engineering/types` 基础型号页面，不修改产品、模板、属性、基础型号或 BOM 的业务表单及保存逻辑。缺少页面权限时保留步骤说明，但不提供跳转链接；没有任何产品页面权限时不展示产品引导。
- HOME 按业务分类展示介绍和功能卡片，每类默认显示四张卡片，“查看更多”展开该分类的其余入口。
- 产品管理分类优先展示产品建档、BOM 配方、产品模板和产品属性配置。
- HOME 是导航页面，不占用“最近访问”的业务页面记录。

## 全厂概览与权限

- `/dashboard` 保持独立，左侧菜单名称为“全厂概览”，保留全厂概览、生产日历、交付进度、系统全域动态四个 TAB。
- 沿用 `menu_dashboard`，权限编辑器中的名称为“访问：全厂概览”。既有 TAB 权限及路由校验继续生效。
- 未获得该域菜单权限的账号看不到全厂概览菜单及 HOME 中的对应分类。直接访问仍由现有路由权限守卫检查。
- `/` 和 `/home` 仅要求有效登录会话，不依赖业务菜单权限，不生成额外的 HOME 业务权限。未登录访问 `/home` 仍跳转登录页。
- 没有业务权限的账号可进入 HOME，并看到无可用业务入口的提示。

## 入口数据来源

首页分类入口从 `sidebar-data.ts` 获取分类与业务域，复用 `sidebar-tab-preview-registry.ts` 中各域的 TAB 配置，并分别应用现有菜单与路由权限过滤。产品操作引导从产品管理和产品结构的 TAB 配置解析目标页面，由 `build-home-product-creation-guide-steps.ts` 定义步骤顺序与文案键；页面文案以当前表单字段和操作为准。

新增业务域或 TAB 时，应维护原有菜单及 TAB 配置。新增顶层分类时，可在 `build-home-business-shortcut-categories.ts` 的分类说明映射和中英文 HOME 词典中补充介绍。

## 验证覆盖

单元测试覆盖 HOME 与概览权限分离、菜单可见性、产品和 BOM 入口顺序、重复入口去重以及未登录跳转。浏览器验证覆盖默认登录跳转、单 TAB、分类展开收起、概览四个 TAB、底部返回 HOME、不同权限账号、手机布局及英文界面。
