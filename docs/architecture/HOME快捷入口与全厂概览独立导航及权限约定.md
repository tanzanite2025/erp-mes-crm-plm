# 首页快捷入口与全厂概览独立导航及权限约定

## 业务入口

- `/home` 是登录后的默认入口，左侧有独立菜单，中文名称为“首页”，英文名称为“Home”，域内只有“快捷入口”一个 TAB。
- 底部首页图标始终指向 `/home`，只在首页显示激活状态。
- “如何建立产品”属于产品域，在“产品管理 → 产品操作手册”分类下独立展示，与“产品配置”分类并列，路由保持 `/engineering/product-creation-guide`。产品工程管理的 TAB 列表不重复展示该入口；手册页面使用自身的单独 TAB。TAB 是说明页，介绍产品档案组成、产品模板和属性分类的复用方式、外观图片及简短建档步骤；进入时不自动弹窗，点击“开始 / 继续建档”才打开分步向导。HOME 只展示带说明的快捷卡片，在当前页打开同一个产品域向导弹窗。
- 说明页采用独立手册样式：顶部集中标题、介绍和建档入口，章节锚点定位资料组成、型号与卡片、建立步骤、展示与维护及配置参考。宽屏右侧展示随阅读位置停留的建立步骤，窄屏按章节顺序排列；展示含义与维护入口分行呈现。章节定位无需业务页面权限，维护入口仍按目标页面权限显示。
- 说明页需讲清三级基础型号、具体产品卡片、聚合名称、产品规格标签和 BOM 标签的含义及维护入口；例如同属 R50 的具体产品可分别保存为 R50（碟刹）、R50（V刹）两张卡片，名称沿用产品编辑底部“最终型号显示预览”。分类、模板、产品及 BOM 的对应关系见[产品模板属性分类业务组件复用](../frontend/product-template-attribute-classification-business-components-reuse-guide.md)。
- 产品模板与模板属性配置统一从“产品模板”进入。属性与选项直接在各自模板中独立维护，随模板一起保存，不提供公共分类库入口、独立属性 TAB、独立分类路由或旧地址兼容跳转。HOME 和操作手册指向 /engineering/templates。
- 向导包含选择模板、确认基础型号、保存产品三步，以及保存产品后的 BOM 第四步。BOM 是产品生命周期管理的必备资料；产品可先保存并结束本次建档，BOM 独立准备和验证确认后，再在 BOM 配方中关联具体产品。本次是否继续第四步由当前操作需要决定。一次仅展示当前步骤，弹窗按内容决定高度并限制最大高度，较长表单在内部滚动。顶部显示编号和完成标记，点击已解锁步骤可返回修改，未来步骤在前置确认完成前禁用。
- 向导第一步只选用已有模板，直接复用其属性与必填规则，无需独立准备属性，也不提供新建模板入口，避免新手重复建立模板。没有可用模板时提示联系负责模板配置的人员确认；模板由专门的模板页面统一维护。基础型号必须解析到选定模板；向导内保存产品使用本次确认的基础型号，若继续 BOM 操作，则关联本次已保存的具体产品。保存成功或已有配置校验通过后标记完成并推进；取消或保存失败保持当前步骤。
- 返回前步时带回已确认的选择；重新确认相同配置保留后续完成结果，更换模板、模板版本或基础型号后清除依赖步骤的确认状态，保留已保存业务记录。返回已保存产品步骤时编辑原记录，避免重复建档。
- 进度按账号保存在当前浏览器，关闭、刷新或再次打开向导可以继续；“建立另一个产品”在当前弹窗内确认后只重置向导进度，保留已保存业务数据。缺少某步骤对应页面权限时保留说明并禁用操作。保存产品后停留在完成面板，可继续 BOM 或完成并关闭。
- HOME 按业务分类展示介绍和功能卡片，每类默认显示四张卡片，“查看更多”展开该分类的其余入口。
- 产品管理分类优先展示“如何建立产品”、产品建档、BOM 配方和产品模板。
- HOME 是导航页面，不占用“最近访问”的业务页面记录。

## 全厂概览与权限

- `/dashboard` 保持独立，左侧菜单名称为“全厂概览”，保留全厂概览、生产日历、交付进度、系统全域动态四个 TAB。
- 沿用 `menu_dashboard`，权限编辑器中的名称为“访问：全厂概览”。既有 TAB 权限及路由校验继续生效。
- 未获得该域菜单权限的账号看不到全厂概览菜单及 HOME 中的对应分类。直接访问仍由现有路由权限守卫检查。
- `/` 和 `/home` 仅要求有效登录会话，不依赖业务菜单权限，不生成额外的 HOME 业务权限。未登录访问 `/home` 仍跳转登录页。
- 没有业务权限的账号可进入 HOME，并看到无可用业务入口的提示。

## 入口数据来源

首页分类入口从 `sidebar-data.ts` 获取分类与业务域，复用 `sidebar-tab-preview-registry.ts` 中各域的 TAB 配置，并分别应用现有菜单与路由权限过滤。产品操作引导从产品管理和产品结构的 TAB 配置解析目标页面，由产品域的 `build-product-creation-operation-guide-steps.ts` 定义步骤顺序与文案键；页面文案以当前表单字段和操作为准。

独立 TAB 对应 `tab_engineering_product_creation_guide`，沿用 `menu_engineering` 的域级授权回退；页面操作继续检查各目标步骤的页面权限，保存接口沿用后端授权。新增路由时同步生成路由树、前端路由权限目录及后端权限契约。

新增业务域或 TAB 时，应维护原有菜单及 TAB 配置。新增顶层分类时，可在 `build-home-business-shortcut-categories.ts` 的分类说明映射和中英文 HOME 词典中补充介绍。

## 验证覆盖

单元测试覆盖 HOME 与概览权限分离、菜单可见性、手册 TAB 注册与授权、快捷卡片入口顺序、重复入口去重、模板直接复用及无新建入口、说明页进入时不弹窗、点击后打开向导、步骤依赖、回退修改、依赖确认失效、关闭恢复进度及保存失败不推进。浏览器验收应覆盖说明页内容和手动打开向导、HOME 原页打开向导、单步显示、确认后推进、回退选择保留、刷新恢复进度、手机布局及英文界面。
