# 生产路线与独立工资计算实施边界

更新日期：2026-10-15。原 PR3/PR4 的“产品路线工价、生产完工自动计件、工资报工结算”目标已撤销，不再作为开发计划。工资只完成财务录入已有人员、部门、独立工资环节与数量后计算金额。

工资当前契约统一见 [`独立计件工资模块契约与实现边界.md`](独立计件工资模块契约与实现边界.md)。

## 2. 工资最终实施范围

1. 维护独立工资环节及环节工价，不引用产品或生产路线。
2. 从既有人事主数据读取人员、部门；不建立另一套工资人员、部门或班组模型。
3. 财务选择人员、部门和工资环节，录入数量与工价日期，直接计算工资。
4. 展示逐行金额及按人员、部门、币种汇总；修改输入后重算。
5. 不包含报工、缺价补录队列、业务单据、审核、结算、收付、作废或调整流程。

工价维护检查版本与区间重叠并记录审计；计算只读取，不创建业务事实，不需要请求回执或工资状态机。

## 4. 迁移约束

独立工价迁移检查存量工价的完整新事实后删除旧生产字段与 `piecePrice/effectiveAt`，不按生产身份猜测映射、不做兼容读取。计算本身没有存储迁移，也不创建工资报工、结算、付款或调整表。

未对业务库执行应用迁移。历史业务表不由本次代码自动删除；不因撤除模型而擅自清理业务数据。

## 5. 验收定义

工资计算能在不存在生产表时完成；已有人事主数据可直接选择，不重复维护。数量与单价采用十进制精确乘法，最终一次舍入到分；缺价、无效人员/部门及超范围输入明确失败。重复计算和修改数量后重算都不写业务记录。

生产执行与扫码在没有工资表或账号员工绑定时仍可完成。此前报工、结算和收付验收属于已撤回实现，不作为当前完成依据。
