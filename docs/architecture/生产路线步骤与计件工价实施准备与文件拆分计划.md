# 生产路线与独立计件工资边界

更新日期：2026-11-24。

本文说明生产路线和计件工资的职责分工。计件工资的完整规则以[独立计件工资模块契约与实现边界](独立计件工资模块契约与实现边界.md)为准。

## 生产路线

生产路线属于生产执行，维护订单行已选 MBOM 分支允许使用的工序和顺序。产品分类只作为订单的识别和展示上下文，不单独决定路线。生产计划按订单明细已选分支及路线排产，并固定当时已发布的路线修订；扫码执行沿用计划绑定的修订。

路线不维护工资人员、部门或工资工价，也不因工序完成而生成工资计算记录。生产执行、路线状态和工资计算使用各自的业务事实。

## 计件工资

1. 独立维护工资环节及各环节工价，不引用产品、MBOM 分支或生产路线。
2. 从既有人事主数据读取人员和部门，不另建工资人员、部门或班组目录。
3. 财务选择人员、部门、工资环节和工价日期，录入数量后计算金额。
4. 展示逐行金额，并按人员、部门和币种汇总；修改输入后重新计算。
5. 工价维护校验有效区间、版本并记录审计；工资计算只读工价和人事选项，不写入业务事实。

工价采用十进制精确运算，最终舍入到分。无有效工价、人员或部门时明确报错。财务可以修改输入后重新计算。

## 实施依据

生产路线修订、发布快照和条码执行关系见[生产线主数据与订单路线分阶段实施设计](生产线主数据与订单路线分阶段实施设计.md)。工资环节、工价维护和计算规则见[独立计件工资模块契约与实现边界](独立计件工资模块契约与实现边界.md)。
