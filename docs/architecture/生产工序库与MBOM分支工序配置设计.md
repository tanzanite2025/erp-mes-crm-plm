# 生产工序库与 MBOM 分支工序配置设计

更新日期：2026-11-26。

## 1. 需求与现状

工序定义在独立工序库维护。`ProcessStep` 是正式、可复用的工序身份，不依赖产品分类或某条产线。稳定 MBOM 分支预设该分支的默认工序及顺序，销售订单明细选择产品分类作为可读上下文并选择有效 MBOM 分支后默认继承。产品分类只负责识别、检索和展示，不单独决定工序或路线。

只有订单对应的 EMBOM 需要个性调整时，订单行才改用本单自定义路线；路线创建不再选择“分支默认/订单明细专用”范围。工序配置独立于产线归属：产线由生产架构的产线 TAB 维护，EBOM 记录所选产线，MBOM 通过来源 EBOM 展示产线。工序库同时提供独立 TAB 和可嵌入其他页面的配置弹窗，两种入口操作同一份服务端数据。

工序库 `ProcessStep` 保存编码、名称、说明、显示顺序和启用状态，并通过 `/production/processes` 接口维护。MBOM 分支配置直接保存稳定分支身份与 `ProcessStep.id` 的关联。路线修订保存工序 ID 及名称、说明快照；`routeStepId` 表示该工序在具体路线中的有序位置。

## 2. 配置入口与组件边界

- 生产架构提供“工序库”TAB，路径 `/production-architecture/process-library`。工序库不依赖产品分类、MBOM 分支或路线，用户可以先维护可复用工序定义。
- `ProductionProcessLibraryConfigurationContent` 负责列表、查询、新建、编辑、启停和删除，编辑表单内嵌，既不包含页面布局也不绑定 Dialog、路由或父页面状态。
- `ProductionProcessLibraryConfigurationPage` 只增加页面标题并承载共享内容；`ProductionProcessLibraryConfigurationDialog` 只增加弹窗、滚动区及关闭保护，并承载同一个内容组件。
- 弹窗允许调用方传入 `onProcessSaved`，返回服务端保存的工序。调用方可刷新候选或定位新工序；配置组件不得擅自替调用方关联 BOM、修改 MBOM 选配草稿或保存路线。
- 查询使用既有工序 query key；成功后写入服务端确认的数据并通知查询缓存，TAB、弹窗和选择器读取同一数据。读取失败显示具体错误与重试，不能伪装为空清单；保存失败保留草稿并允许重试。
- 写权限沿用接口的 `perm_manage`，只读权限不显示写操作；嵌入到其他页面不能扩大访问权限。没有生产配置读取权限时不发起工序查询。
- 保存期间阻止重复提交、切换编辑对象和关闭弹窗；未保存草稿关闭时需明确放弃确认。窄屏可滚动，列表和表单无横向溢出。
- 独立 TAB 与嵌入弹窗共用配置内容组件和服务端数据。

## 3. MBOM 分支工序与路线边界

MBOM 分支工序配置以稳定 MBOM 分支身份为归属，以 `ProcessStep.id` 为被选对象，不按名称匹配。必须保存“MBOM 分支—工序库”的明确关联及默认顺序；不复制工序名称来创建第二套 MBOM 操作身份。

同一工序可以被多个 MBOM 分支选用，同一分支的重复关联要拒绝。某个 MBOM 分支调整工序配置不能改动其他分支。工序库新增或编辑不自动替任何分支建立关联，也不发布或覆盖路线。

MBOM 分支工序及顺序构成该分支的默认路线；默认订单行直接继承。订单对应 EMBOM 需要个性调整时，订单行选择本单自定义工序。生产路线 TAB 直接选择该订单行配置工序，产品分类只从订单行读取为展示上下文，MBOM 分支从订单行读取为实际约束；路线名称和编号由系统生成。

MBOM 分支工序的默认顺序由分支配置维护；订单路线按订单行从该分支选用工序并定义执行顺序。工序库名称、说明和顺序的修改不改写已发布路线或历史事实快照；启用状态修改只允许在没有有效分支关联时停用。删除或停用已被 MBOM 分支关联的工序由服务端校验并返回引用冲突。工序库配置入口只维护工序定义，不写 MBOM 分支配置、路线或执行事实。
