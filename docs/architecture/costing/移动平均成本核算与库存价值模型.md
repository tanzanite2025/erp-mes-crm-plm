# 移动平均成本核算与库存价值模型

## 1. 目标

建立“数量 + 价值”双维度库存模型，确保：

1. 入库时自动重算平均成本；
2. 出库时固定成本快照（COGS）；
3. 异常场景触发 Fail Loudly，防止静默错误。

---

## 2. 数据模型增强

## 2.1 Inventory（库存余额）

新增字段：

- `TotalValue`：本位币总价值
- `AverageUnitCost`：加权平均单位成本

现有 `Quantity` 与新增价值字段共同构成库存核算基础。

## 2.2 InboundRecord（入库记录）

建议新增字段：

- `PurchaseOrderID`
- `SupplierID`
- `PurchasePrice`
- `Currency`
- `RateSnapshotID`（可选）

## 2.3 ShipmentRecord（出库记录）

建议新增字段：

- `SalesOrderID`
- `CustomerID`
- `COGS`（出库成本快照）
- `RateSnapshotID`（可选）

---

## 3. 移动平均法公式

设：

- 旧库存量 `Q_old`
- 旧平均单价 `C_old`
- 本次入库量 `Q_in`
- 本次入库单价 `C_in`

计算：

- `V_new = Q_old * C_old + Q_in * C_in`
- `Q_new = Q_old + Q_in`
- `C_new = V_new / Q_new`

其中：

- `V_new` 为新总价值
- `C_new` 为新平均单价

---

## 4. 原子化事务流程

入库时必须在单事务内执行：

1. 锁定库存记录（`SELECT ... FOR UPDATE`）；
2. 读取 `Q_old`、`C_old`；
3. 计算 `V_new`、`Q_new`、`C_new`；
4. 更新 `Inventory.Quantity / TotalValue / AverageUnitCost`；
5. 写入 `InboundRecord`；
6. 提交事务。

若任一步失败，整单回滚。

---

## 5. 出库成本快照（COGS）

出库提交时：

1. 锁定库存记录；
2. 校验可用库存数量；
3. 以当前 `AverageUnitCost` 计算并快照 `COGS`；
4. 扣减 `Quantity` 与 `TotalValue`；
5. 写入 `ShipmentRecord.COGS`；
6. 提交事务。

原则：出库后不得因后续入库重算而改写历史 COGS。

---

## 6. Fail Loudly 保护规则

1. 零分母保护：
   - 当 `Q_new == 0` 时抛出 `[CRITICAL_LOGIC_ERROR]` 并回滚事务。
2. 负库存保护：
   - 出库后若库存将小于 0，抛出 `[CRITICAL_STOCK_SHORTAGE]`。
3. 非法数值保护：
   - `PurchasePrice < 0` 或 `Q_in <= 0` 时拒绝入账并返回校验错误。
4. 并发冲突保护：
   - 行锁冲突或版本冲突必须显式返回，不允许静默重试覆盖。

---

## 7. 一致性校验

1. `Quantity * AverageUnitCost` 应与 `TotalValue` 在精度范围内一致；
2. 出库后库存价值减少额应与 `COGS` 合理对齐；
3. 历史期间补录不应覆盖已过账期间 COGS，差异走调整凭证。

---

## 8. 回归验证用例

1. 连续两次不同单价入库，验证均价更新；
2. 入库后立即出库，验证 COGS 快照固定；
3. 构造 `Q_new == 0` 场景，验证 CRITICAL 回滚；
4. 并发入库同物料同批次，验证无价值漂移；
5. 汇率变化下多批入库，验证本位币价值一致性。
