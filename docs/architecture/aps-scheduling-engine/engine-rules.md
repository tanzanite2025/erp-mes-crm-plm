# APS 排产引擎 - 规则与约束

## 1. 目标

本文件用于描述排产时的基本规则，重点解决“先排谁、哪里能排、什么时候不能排”。

## 2. 核心规则

### 2.1 优先级规则

建议优先级从高到低考虑：

1. 紧急单
2. 交期临近订单
3. 普通订单
4. 可延后订单

### 2.2 产能约束

排产必须满足：

- 产线可用
- 对应 L2/L3 节点可用
- 人员可用
- 设备可用
- 班次可用

### 2.3 日历约束

默认情况下：

- 工作日可排
- 休息日不可排
- 法定节假日不可排
- 临时加班日按规则可排

### 2.4 冻结区规则

已经开始执行或已经确认的计划，不允许随意改动。

建议分区：

- 已执行区：不可动
- 冻结区：慎动
- 可重排区：允许调整

### 2.5 拆单与合单规则

如果订单需要拆分或合并，必须先定义清楚：

- 哪些订单可拆
- 哪些订单可并
- 拆分后是否允许跨天
- 拆分后是否允许跨线

## 3. 动态修正规则

当出现以下事件时，可触发重排：

- 条码记录显示休息日有人上班
- 设备提前恢复
- 设备故障
- 缺料补齐
- 人工插单
- 订单变更

## 4. 简化原则

第一版规则不要太多，建议先只做：

1. 优先级
2. 日历
3. 产能
4. 冻结区
5. 动态重排触发
