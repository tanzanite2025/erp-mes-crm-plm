# APS 排产引擎 - 数据模型

## 1. Order

订单是排产入口，包含：

- 订单号
- 交期
- 优先级
- 数量
- 状态
- 是否允许拆分

## 2. Resource

资源表示可被占用的生产能力，包含：

- 产线
- 工位
- 设备
- 人员
- 班组
- 班次

## 3. Calendar

日历用于判断能不能排，包含：

- 工作日
- 休息日
- 节假日
- 停线日
- 加班日

## 4. SchedulePlan

排产结果对象，包含：

- 关联订单
- 关联资源
- 开始时间
- 结束时间
- 版本号
- 状态

## 5. ScheduleEvent

动态事件对象，包含：

- 条码记录
- 签到记录
- 设备状态变化
- 缺料
- 人工调整
