# APS 排产引擎 - 动态事件修正

## 1. 事件来源

### 条码事件

用于识别：

- 人员到岗
- 休息日是否实际开工
- 班次是否真实发生

### 设备事件

用于识别：

- 开机
- 停机
- 故障恢复
- 维护结束

### 物料事件

用于识别：

- 缺料
- 到料
- 是否恢复可排产

### 人工事件

用于识别：

- 插单
- 改排
- 锁定计划

## 2. 调整方式

- 局部修正
- 局部重排
- 全局重排
- 版本更新

## 3. 特殊场景

如果休息日有条码记录，系统应自动：

1. 标记当天可用产能变化
2. 更新排产结果
3. 记录触发原因
4. 必要时重算局部计划
