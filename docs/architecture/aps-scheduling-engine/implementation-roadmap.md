# APS 排产引擎 - 实施路线图

## 1. 目标

本文件用于把排产引擎拆成可执行的小步骤，避免一次性把系统做得过于庞大。

## 2. 推荐阶段

### 阶段一：基础模型

先把以下内容跑通：

- 订单模型
- 资源模型
- 日历模型
- 排产结果模型

### 阶段二：静态排产

实现最基础的排产计算：

- 按优先级排序
- 按资源分配
- 按日历过滤
- 生成首版排产结果

### 阶段三：动态修正

接入现场事件：

- 条码记录
- 签到记录
- 设备状态
- 缺料事件

### 阶段四：版本与审计

增加：

- 排产版本
- 重排差异
- 审计记录
- 回滚能力

## 3. 先做什么

如果只想先做一个简单版本，建议先做：

1. 数据模型
2. 静态排产
3. 日历约束
4. 条码事件记录

## 4. 暂不做什么

第一版可以暂时不做：

- 复杂优化算法
- AI 自动推荐
- 多目标求解器
- 仿真沙盘

## 5. 简化原则

先把“能排、能改、能追踪”做出来，再逐步升级算法能力。
