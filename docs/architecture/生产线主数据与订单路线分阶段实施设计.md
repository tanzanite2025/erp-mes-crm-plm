# 产品分类、MBOM 分支工序、产线归属与生产路线

更新日期：2026-11-27。

本文规定产品分类、具体产品、EBOM、生产 MBOM 分支、工序库、产线、生产路线、销售订单和生产计划之间的业务边界及分阶段实施顺序。产品分类用于识别和展示，产线是独立主数据，EBOM 记录所属产线，MBOM 通过来源 EBOM 显示该归属；MBOM 稳定分支负责工序预设，生产路线负责订单行的实际执行顺序。产线归属只提供业务识别与展示上下文，不决定订单、计划、排产资源、MRP、领料或扫码执行。

## 1. 产品、分类与 MBOM 分支

`ProductType` 是产品分类标签，例如“山地车圈”。分类的作用是让人员理解、检索和归类产品，不单独决定工序、路线、BOM 候选、客户归属、排产或执行规则。`ProductTemplate` 只定义产品需要填写的规格字段，不是产品分类、产线、BOM 或工艺身份。

一张产品卡片对应一条 `Product`，通过 `Product.typeId` 归属产品分类并保存具体型号及规格。BOM 定义具体产品的物料组成，并承载配方版本和生命周期；MBOM 通过 `productId` 关联具体产品。BOM 内的 `BOMSection` 只是物料分组，也不能推导生产工序。

MBOM 稳定分支由以下身份确定：

```text
productId + ownerType + ownerCustomerId + versionLevel
```

`bomId`、BOM 修订号和生命周期状态属于分支中的配方版本，不改变分支身份。同一稳定分支在同一 BOM 类型下最多存在一条 `RELEASED` 记录；修订时旧记录转为 `OBSOLETE`，再发布新记录。订单行只选择一个有效 MBOM 稳定分支，不选择多个 BOM 分支。`Product.typeId` 只用于校验分支所属产品分类并提供可读展示。订单界面可以展示“产品分类 + 有效 MBOM 稳定分支”作为一个完整的销售生产组合上下文，但分类不是第二个工序归属，也不能单独创建或继承工序。

一个具体产品可以关联多个归属或性能版本不同的 MBOM 分支；同一分类下的不同产品或分支可以拥有不同的工序集合。

## 2. 工序与路线

工序库中的 `ProcessStep` 是正式、可复用的工序身份。MBOM 稳定分支直接关联允许使用的工序及默认顺序：

```text
ProcessStep 工序库
  -> MBOMBranchProcessAssociation
     具体 MBOM 分支允许使用的工序及默认顺序
```

MBOM 分支工序的归属是具体 MBOM 稳定分支，不是产品分类名称，也不依赖产线。分支预设工序及顺序是默认路线来源；工序库改名、说明或全局排序不能改写已发布路线和历史执行事实。

产线是独立主数据，具有独立编码、名称、说明和启用状态，不从产品规格模板生成名称。新建 EBOM 时单选一条有效产线并保存归属；同一产线可以关联多个 EBOM。MBOM 通过 `SourceEBOMID` 追溯来源 EBOM，并从该 EBOM 展示产线归属，不另行选择产线。关系链为：

```text
ProductionLine（独立产线主数据）
  <- EBOM.productionLineId（新建 EBOM 时单选）
       <- MBOM.SourceEBOMID（派生来源，产线只读展示）
```

产线归属用于识别和展示 BOM 属于哪条产线，不决定订单行 MBOM 分支、生产计划、路线、APS 资源、MRP、领料或扫码执行。实际作业泳道来自独立作业数据；实际扫码地点由 `ProductionWorkLocation` 表达。工序及默认顺序只归属于具体 MBOM 稳定分支，资源与执行能力由各自领域单独配置。

销售订单明细选择产品分类和有效 MBOM 稳定分支后，默认继承该分支的工序及顺序。只有该订单对应的 EMBOM 在生产期间需要个性调整时，订单行才显式改用本单自定义路线；路线负责订单实际采用的工序子集和顺序，不由产品分类自动覆盖。

生产计划继承来源订单明细的默认/自定义路线，并在排产时固定实际采用的路线快照。后续修改分支默认工序或订单自定义路线，不改写已排产计划和条码；产线归属不参与计划身份。没有销售订单明细来源的计划使用所选 MBOM 分支的默认路线。

## 3. 产线管理与 EBOM 归属

产线 TAB 维护独立的 `ProductionLine` 主数据，包括编码、名称、说明和启用状态。同一产线可以被多张 EBOM 关联。EBOM 草稿必须单选一条有效产线，草稿编辑时可调整；发布锁定后归属保持不变。MBOM 不保存独立产线值，详情始终通过 `SourceEBOMID` 只读读取来源 EBOM 的产线。产线选项通过工程权限下的精简只读接口提供，不要求 BOM 编辑者拥有生产配置权限。产线记录仍被 EBOM 引用时，服务端拒绝删除。

产线归属只用于识别和展示 BOM 属于哪条产线，不决定订单行 MBOM 分支、工序、生产计划、路线、APS 资源、MRP、领料或扫码执行。实际作业地点由 `ProductionWorkLocation` 表达；APS 资源与路线步骤的能力约束由 APS 单独建模。

## 4. 路线与执行约束

- 分支工序配置时校验稳定 MBOM 分支及有效工序库条目，并维护该分支默认工序顺序；产品分类只作为分支归属的可读展示和校验上下文。
- 生产路线 TAB 选择销售订单明细后，默认展示该行所选 MBOM 分支的预设工序及顺序。用户可选“默认工序”或“重新定义”；重新定义时从该分支工序中勾选本单工序、调整顺序并维护执行参数。
- 保存自定义路线时订单行在同一事务内切换为自定义模式；恢复默认时更新订单行模式，已有生产计划不允许切换。路线名称和编号由系统生成，不提供额外适用范围选择。
- 已发布路线修订不可原地修改或删除。排产时服务端固定订单行实际采用的路线快照，客户端不能指定或覆盖路线版本。
- 条码执行只读取计划绑定的路线修订。当前步骤由服务端依据条码状态推进，客户端不提交路线、路线步骤或工序身份；执行事实通过路线步骤和工序库身份追溯。
- MRP 与领料所用 BOM 配方修订必须属于订单明细已选 MBOM 稳定分支，不能改变订单的生产组合。
- MBOM 分支工序、路线步骤、生产位置及委外持有方分别使用各自身份，其中一类记录不能替代另一类。

## 5. 当前状态与实施顺序

独立工序库、MBOM 分支工序配置、销售订单行组合及路线方式、订单行自定义路线、默认路线物化、计划路线修订绑定和扫码固定路线修订均已实现。分支关联、路线和执行事实统一引用 `ProcessStep.id`，路线位置使用独立的 `routeStepId`。产品分类只提供可读归类和分支校验上下文，不单独承载工序逻辑。

EBOM 单选有效产线、发布后锁定归属、MBOM 沿来源 EBOM 展示产线的服务和 SQLite 回归已通过。PostgreSQL 派生与修订专项回归尚未执行，因为未配置 `BOM_LIFECYCLE_TEST_POSTGRES_DSN`。

各阶段按以下顺序实施和验收：

1. [已完成，2026-11-26] 限制路线候选为 MBOM 分支已关联的工序，并由服务端拒绝未关联工序。
2. [已完成，2026-11-26] 建立独立 MBOM 分支工序配置入口。
3. [已完成，2026-11-26] 统一 MBOM 分支关联、路线步骤、条码状态、生产执行、质量和委外事实使用 `ProcessStep.id`；`routeStepId` 独立标识路线位置。
4. [已完成，2026-11-26] 建立销售订单行的产品分类展示上下文与有效 MBOM 稳定分支选择；分支工序及顺序作为默认路线，订单行可在默认与重新定义之间切换。
5. [实现完成，2026-11-27；本地服务层、HTTP 与前端回归已覆盖，浏览器连接实际 API 的端到端验收待完成] MRP 与领料的配方限制在订单明细唯一已选 MBOM 稳定分支内。候选按 `ProductID + BOMOwnerType + BOMOwnerCustomerID + BOMVersionLevel` 精确匹配，客户与内部归属不回退；唯一当前有效的已发布 MBOM 自动采用。重复发布属于数据完整性异常并阻断来源，不提供用户挑选，也不按排序猜选。
6. [已完成，2026-11-26] 工序统一由 MBOM 分支工序配置维护。
7. [已完成，2026-11-27] 建立独立产线主数据维护入口，产线资料只维护编码、名称、说明和启用状态。
8. [实现完成，2026-11-27；PostgreSQL 专项回归待执行] EBOM 草稿新建时必须单选有效产线，草稿修改可调整，发布锁定后不可变；MBOM 不存独立产线字段值，读取时只沿 `SourceEBOMID` 展示来源 EBOM 产线。工程权限可读取启用产线选项，服务端拒绝无产线 EBOM 及删除仍被 EBOM 引用的产线；当前服务及 SQLite 测试已通过，PostgreSQL 派生与修订专项回归因未配置 `BOM_LIFECYCLE_TEST_POSTGRES_DSN` 尚未执行。
10. [已完成，2026-11-27] APS 看板按排程任务的产线名称生成时间轴泳道。
11. [进行中] 完成本地回归、PostgreSQL 专项验证、浏览器 API 端到端验收及目标环境数据库核对。
12. [后续阶段] 主体路线和厂内执行链路验收后，再扩展委外功能；委外遵循[生产委外执行链路设计](生产委外执行链路设计.md)中的边界。

各阶段不得让产品分类单独生成工序，也不得通过产品名称、分类名称、订单客户或最新 BOM 自动推断路线。
