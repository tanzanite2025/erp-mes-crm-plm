# 产品编码（一维码 / 二维码）操作手册：内容、导航与职责边界

## 目的

本手册说明当前已实现的产品编码操作入口及其数据边界，涵盖资料准备、规则配置、标签打印、产品绑定和生产扫码读取。它不表示产品的全部工序和跨域生命周期已经完成。手册入口与“如何建立产品”“如何建立 BOM”一样，统一放在产品管理侧边栏的“产品操作手册”目录中。

手册页面只组织说明内容，并通过入口链接复用现有编码业务页面。它不复制协议表单、打印表单、发号逻辑、二维码渲染逻辑或生产扫码表单。

## 章节范围

1. **先认识编码**：说明一维码和二维码是同一枚产品编码的两种图形表达。
2. **准备资料**：说明产品、订单行快照、外观位值、孔型孔数编码源和共享发号规则的来源。
3. **配置编码规则**：说明协议规则、孔型孔数编码源和共享发号引擎的职责边界。
4. **生成与打印**：说明销售订单选择、预打数量、阻断原因、标签预览和单码/双码排版。
5. **绑定与现场使用**：说明产品绑定、生产执行扫码及生命周期记录与品检现场扫码的边界。
6. **状态与异常**：说明可用、已绑定、已失效、已报废、补打和渲染/预览异常。

## 一维码与二维码边界

- 同一个 15 位原始产品编码可以同时渲染为 Code128 和 QR Code。
- 选择一维码、二维码或双码只改变标签排版，不建立两个流水号、库存记录或状态机。
- 补打使用历史原编码，不重新发号。
- 状态定义和状态变更仍以编码中心及其后端契约为准。

## 产品绑定实际对象

产品绑定页消费可用的已签发产品码，将其与已激活的预浸料卷实例二维码建立绑定；当前事务不记录裁纱执行单 ID，也不是产品主数据关联入口。该绑定用于原材料追溯，不是首次生产 `START` 的前置条件。

## 现场扫码与品检边界

巴枪、摄像头或手工输入均使用标签上的同一个产品编码。生产执行页读取后显示当前工序及该码已记录的生产状态事件、工序操作和流转事件；三类记录分别计数并分页，扫描本身不提交工序操作。首次 `START` 使用规范化后的同一产品编码写入操作、生产状态和状态事件；重放相同请求不会重复写入。当前状态为 `IN_PROGRESS` 时，不允许以新请求再次 `START`；已完成的同一工序必须先登记返工。生命周期读取失败时应重试，不能将读取失败当成“没有历史”。

若页面提示尚无生命周期记录，先核对编码，并确认该码是否尚未进入生产执行；这只表示当前查询不到生产状态记录，不能据此判断编码库存是否有效。

生产执行页的生命周期区域只说明当前生产域已记录的事实，目前不包含产品绑定事件，也不是完整的产品跨域时间线；绑定记录仍通过产品绑定查询单独读取。该页面也不代表完整的检验站录入、品质判定、仓储或售后历史。编码中心提供可引用的编码，生产执行负责工序操作；品检站录入仍属于后续现场业务。

当前四个品检站（成型检验站、机加检验站、精细检验站、涂装检验站）的现场扫码录入链路不在本手册中扩展。手册只说明该边界，避免把编码配置和品检业务混成一套表单或状态机。
