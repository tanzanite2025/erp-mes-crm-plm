# 采购与销售操作指南：内容、导航和权限边界

## 页面和入口

购销管理下设“购销操作指南”分组，分别进入：

- 采购操作指南：`/purchase/purchase-operation-guide`。
- 销售操作指南：`/trading/sales-operation-guide`。

两个入口接入现有侧栏、首页、全局页面搜索和最近访问。指南使用独立阅读页签，不重复加入采购、销售的业务页签列表。原采购、销售页面保持原有入口；侧栏活动状态按业务页签路径匹配，阅读指南时只高亮指南分组。

指南使用与产品手册一致的固定介绍、章节导航和正文滚动布局，支持明暗主题、窄屏及中英文。切换章节只重置正文阅读位置。每页五章，每章包含开始前准备、三个操作步骤、完成后核对、常见问题及可访问的业务页面。

## 已核对的业务边界

| 环节 | 指南遵循的现有实现 |
| --- | --- |
| 采购资料与下单 | 供应商、物料和结算配置归各自业务域维护；保存拟定订单与正式下单分别核对。 |
| 采购物流与收货 | 物流签收不能替代仓库收货。原采购收货弹窗逐行确认本次数量、批次和仓位，并提交原收货入库事务。离线物流草稿须同步成功才算正式提交。 |
| 采购退货 | 当前可办理订单为 `Sent` / `Awaiting`，数量范围为订购减已收减已退，与 `getPurchaseOrderRemainingQty` 和服务端 `purchase_return_service.go` 一致。不能描述为已入库库存的通用退供应商出库。 |
| 销售产品 | 基础型号不等于具体产品卡片，订单应核对实际产品与规格。 |
| 销售交付 | 仓库按订单行转入虚拟发货仓；配车消费真实发货记录。订单状态、库存记录及物流执行分别核对。 |
| 销售售后 | 退货创建、回仓确认、实际退货金额登记分别核对；换货继续跟踪旧件回仓、替换件准备和补发。 |
| 应收应付 | 复用原订单财务明细入口及 `/finance-settlements`；采购读者进入后切换应付。指南不自行创建台账、登记收付款或推算财务完成状态。 |

## 文件职责和权限

`src/components/chaptered-business-operation-guide-page.tsx` 只负责阅读布局、翻译显示和按目标页面权限筛选链接。章节、操作顺序和目标入口分别位于 `features/purchase/data/purchase-operation-guide-chapter-definitions.ts` 与 `features/trading/data/sales-operation-guide-chapter-definitions.ts`。说明文本由两个业务域的中英文指南词典维护。

阅读不调用业务接口，不加载业务表单或保存 Hook，也不保存模拟办理进度。指南页面不授予业务操作权限。链接使用现有目标路由，物料档案沿用分类路由参数，不附加目标模块尚未支持的自动办理参数。

两个指南从现有路由目录派生独立 TAB 权限：`tab_purchase_purchase_operation_guide`、`tab_trading_sales_operation_guide`。既有采购、销售模块权限沿用现有回退规则；仅有业务 TAB 权限不自动授予指南，仅读指南也不授予业务访问。后端路由权限白名单和管理员回退清单由原生成脚本更新。

## 验证范围

新增回归覆盖五章阅读、正文滚动重置、无业务请求、仅读权限、目标链接隔离、物料分类参数、中英文内容、关键业务边界、侧栏活动状态、首页、搜索及最近访问。配合原搜索覆盖、首页和最近访问回归核对导航兼容性。

本次为操作手册与合法页面导航，未增加自动建单、退货、收发货或财务办理流程。后续如增加步骤办理入口，必须复用原领域动作、权限与真实业务记录。
