# Chrome 109 浮层与左侧菜单兼容约定

公司 Win7 电脑的浏览器兼容基准为 Chrome 109。已处理浮层的背景和文字可读性，包括侧栏快捷导航、对话框、抽屉、菜单、选择器、Popover 和 Tooltip。2026-10-17 按区域逐项排查时，增加了左侧菜单本体的颜色兼容。业务页面与底部菜单栏的后续修复见[业务页面与底部菜单栏颜色兼容记录](./chrome109-business-page-and-bottom-dock-color-compatibility.md)。

## 样式边界

- `src/styles/theme.css` 继续作为现代浏览器的主题来源。
- `src/styles/chrome109-overlay-color-fallbacks.css` 只在不支持 OKLCH 颜色时生效。
- 回退颜色仅在浮层根节点、`[data-slot='sidebar']` 及其后代中使用，不能改成 `:root` 或 `body` 上的全局覆盖。
- `src/styles/chrome109-sidebar-menu-color-fallbacks.css` 单独处理左侧菜单的透明度和导航状态，同样只在不支持 OKLCH 时生效。主题颜色复用浮层回退表，避免维护两份主题值。
- 使用语义角色识别通用浮层；没有对应角色的自定义浮层使用明确的 `data-slot`。
- 知识详情抽屉、知识编辑弹层与车型联系人删除确认框通过专用 `data-slot` 纳入兼容范围，保留原有组件样式和业务行为。
- sRGB 回退值对应现有主题颜色。修改主题时同步核对浅色、深色回退值。
- 只设置弹窗的默认文字颜色，并保留工具类的优先级，避免破坏反色提示和业务状态文字。

## 验收要求

1. 使用真实 Chrome/Chromium 109 内核。修改新版浏览器的 User-Agent 不能替代旧内核验证。
2. 浅色、深色主题分别检查侧栏导航、普通弹窗、菜单与选择器；浮层应遮住底层文字，标题和操作项应可读。
3. 检查关闭按钮、Escape、菜单选择，以及弹窗内继续打开选择器的场景。
4. 比较修改前后的现代浏览器截图；冻结动画后，代表页面的截图像素和计算样式应保持一致。
5. 检查浮层以外的卡片计算样式，确认没有被兼容规则影响。
6. 在 Win7 实机上复核字体、缩放与实际交互；其他操作系统上的 Chromium 109 验证不等同于 Win7 实机验收。

此修复不代表所有业务模块已经完成 Chrome 109 验收。后续浏览器 API、打印和计算功能的兼容问题应根据实际复现单独处理。

## 本次验证记录

- 在较新 Windows 上使用真实 Chromium 109.0.5414.46，复现了原侧栏浮层背景透明、底层文字穿透的问题。
- 修复后检查了浅色、深色的侧栏快捷导航、普通对话框、知识详情抽屉、知识编辑框、编辑框内页面选择浮层、车型联系人删除确认框、车型类别选择器和语言菜单；背景与文字可读，选择、取消及普通对话框和菜单的 Escape 关闭正常。
- Chromium 155 的代表页面在动画稳定后，侧栏浮层和普通对话框的浅色、深色截图均与修改前逐像素一致。浮层外的 5 张看板卡片计算样式保持一致。
- 从最终生产 CSS 中移除新增的旧浏览器条件块后，剩余 CSS 与修改前逐字节一致。
- 生产构建、所改组件的 ESLint、所改文件的 Prettier 和 `git diff --check` 均通过。浏览器检查使用本地模拟接口。
- Win7 实机复核尚未完成。

## 2026-10-17 左侧菜单验证记录

- 基于 `cf529ef5` 的生产 CSS 复现：Chrome 109 的菜单背景透明、普通边框回落为黑色、深色主题文字失去对比度，当前分类图标的橙色也未正常显示。
- 在真实 Chromium 109.0.5414.46 中检查了浅色、深色主题的普通状态、其他分类预览、当前分类预览和键盘焦点。菜单背景恢复不透明，普通边框恢复浅色或深色的半透明值，当前分类始终保留橙色高亮。
- 分类悬停、跨浮层移动、两秒延迟关闭、分类切换、Escape、遮罩关闭和移动端点击展开均通过。Ctrl+B 收起、按钮展开、切换到“环节与工价”后返回“产品管理”的路由及分类高亮均通过。
- 1366×768 视口中，全部 12 个分类按钮位于可视范围内。此检查不代表所有分辨率和系统缩放均已验收。
- Chromium 155 的浅色、深色共 8 组修改前后整页截图逐像素一致。菜单尺寸、位置未改变；菜单外业务内容和已修复浮层的计算样式未改变。
- 从生产 CSS 中移除 Chrome 109 条件块后，其余 CSS 与本次修改前逐字节一致。生产构建、修改文件的 Prettier 和 `git diff --check` 通过。
- 浏览器检查使用本地模拟接口，在较新 Windows 上运行旧内核；仍需 Win7 实机复核。本轮未部署服务器，业务页面和底部栏的兼容问题不在本轮修复范围。
