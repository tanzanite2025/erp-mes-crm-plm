# 产品绑定 TAB 职责边界

产品编码库存及生产履历边界以[产品编码生命周期契约](../../../../../docs/architecture/linear-barcode-lifecycle-contract.md)为准。

本 TAB 是产品编码与预浸料卷实例的追溯绑定入口：

- 扫描已激活的预浸料卷二维码和已签发产品编码
- 通过后端唯一绑定事务完成 `AVAILABLE -> BOUND`
- 重复提交相同绑定时回显原记录，不重复累计批次计数

过期只在绑定事件发生时判定：后端只刷新当前扫描的产品码。未扫描的其它库存码不得被批量计算或后台改写。

绑定记录用于原材料追溯，不是普通生产开工的前置条件。生产操作、生产状态与生产事件通过生产扫码服务另行写入；生产履历查询当前不包含绑定事件，绑定记录仍单独查询。

本 TAB 不得接受未签发、已过期、已报废或已被其它绑定占用的产品码，也不得绕开绑定服务直接修改库存。
