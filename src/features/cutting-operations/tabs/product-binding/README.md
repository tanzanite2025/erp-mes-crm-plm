# 产品绑定 TAB 职责边界

完整状态机以[一维码生命周期契约](../../../../../docs/architecture/linear-barcode-lifecycle-contract.md)为准。

本 TAB 是产品一维码消费入口：

- 扫描已激活的预浸料卷二维码和已签发产品一维码
- 通过后端唯一绑定事务完成 `AVAILABLE -> BOUND`
- 重复提交相同绑定时回显原记录，不重复累计批次计数

过期只在绑定事件发生时判定：后端只刷新当前扫描的产品码。未扫描的其它库存码不得被批量计算或后台改写。

本 TAB 不得接受未签发、已过期、已报废或已被其它绑定占用的产品码，也不得绕开绑定服务直接修改库存。
