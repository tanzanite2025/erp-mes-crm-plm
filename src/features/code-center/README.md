# 编码中心职责边界

一维码跨 TAB 生命周期以[一维码生命周期契约](../../../docs/architecture/linear-barcode-lifecycle-contract.md)为准。

本 feature 的一维码打印入口负责：

- 选择可打印销售订单行并填写 1 到 200 的预打数量
- 调用后端原子批量签发接口
- 在一个预览窗口生成全部 Code128 标签
- 展示逐码库存、批次、状态和到期时间

本 feature 的一维码状态入口负责：

- 读取后端 `GET /code-center/linear-barcode/status-contract` 状态契约
- 展示一维码打印库存状态和生产执行状态分别有哪些
- 说明每个状态的触发方式、数据表来源、是否终态
- 明确生产执行状态是一级状态，`routeStepId/currentProcessStepId` 是该状态下的 L3 二级定位
- 明确状态定义是只读契约边界，不是查询或直接修改某个一维码当前在哪里

本 feature 不得：

- 在前端生成或保留真实流水号
- 直接把库存码改为 `BOUND`、`EXPIRED` 或 `SCRAPPED`
- 在页面轮询或后台扫描整张库存表
- 用一维码状态替代产线 L1/L2/L3 定义，或要求先绑定卷材才能继续普通生产
- 在状态定义 TAB 中承载单码实时追踪查询；后续追踪查询应独立放入追溯/执行链路
- 在前端维护完整状态数组作为后端状态机兜底
